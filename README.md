# hallo-test
一：Ubuntu 与 ROS 环境搭建
 
一、环境信息
 
- Ubuntu 版本：20.04.6 LTS
- ROS 版本：Noetic
- 虚拟机软件：VMware Workstation
 
二、安装过程与遇到的问题
 
1. 虚拟机软件选择
 
搭建ROS环境前，我在VirtualBox与VMware之间进行选择，优先尝试VirtualBox。但在ROS安装过程中，电脑出现黑屏并直接关机，虚拟机提示异常退出。我查阅B站教程，同时借助AI工具尝试多种排错方案，问题始终无法解决。为了不耽误任务进度，更换虚拟机软件，改用VMware进行部署。
 
2. VirtualBox虚拟机锁定无法修改配置
 
VirtualBox异常退出后，虚拟机处于锁定状态，设置选项全部灰色无法点击。尝试删除锁文件、执行命令、重启主机等多种方式，依旧无法解除锁定，无法继续调整虚拟机内存、显卡等配置，这也是后续运行崩溃的诱因之一。
 
3. ROS安装网络报错
 
切换到VMware装好Ubuntu后，安装ROS时出现网络与DNS报错，软件源访问失败。解决办法：修改虚拟机网络为桥接模式，更换国内镜像源，重新更新软件包，ROS密钥添加与环境变量配置顺利完成。
